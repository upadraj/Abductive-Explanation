# Formal Abductive Explanations for Deep Neural Networks: Solvers, Bound Propagation, and Abstraction–Refinement

Reading list for a survey of formal (abductive) explanations of deep neural networks, organized by how the explanation is computed: exact SMT/MILP solvers, bound propagation, and abstraction–refinement. Also covers the surrounding work the survey draws on — preimage computation, hyperproperties, and explainability for learned controllers.

## Tag glossary

- **abductive explanation** — minimal subset of input features that provably suffices for the prediction (a.k.a. prime-implicant / sufficient-reason explanation)
- **contrastive explanation** — minimal set of features whose change can flip the prediction; dual to abductive explanations
- **formal XAI / logic-based XAI** — explanations with formal guarantees, computed with SAT/SMT/MILP solvers or bound propagation
- **heuristic XAI** — non-formal, sampling-based explainers (LIME, SHAP, Anchors) used as baselines
- **verification / solver / bound propagation** — the underlying machinery (Reluplex, Marabou, Z3, CROWN family) used to certify explanations
- **preimage / global explanation** — characterizing the whole input region that maps to a given output, rather than a single instance
- **hyperproperties** — properties over multiple executions (robustness, fairness, information flow)
- **abstraction / network reduction** — shrinking the network to make solving tractable, then refining
- **RL / learned controller / planning / robotics** — explanation and verification of policies and controllers rather than classifiers
